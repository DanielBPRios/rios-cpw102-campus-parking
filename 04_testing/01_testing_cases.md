# Test Cases

## Test Case 1: Valid Input

**Input / Action:**  
Enter [a valid input] 60

**Expected Result:**  
The program calculates and displays the correct [output]

**Actual Result:**  
Results in correct showing that the total cost is $2.00 and that they have
parked for two hours.

**Result:**  
**Pass** / Fail

---

## Test Case 2: Boundary Input

**Input / Action:**  
Enter the minimum or maximum allowed [input] 0

**Expected Result:**  
The program handles the boundary value correctly.

**Actual Result:**  
The program correctly calculates the minimum to be both $0.00 and that they
have stayed for 0.00 hours.

**Result:**  
**Pass** / Fail

---

## Test Case 3: Invalid Input

**Input / Action:**  
Enter an invalid value (such as text when a number is expected) "i"

**Expected Result:**  
The program handles the invalid input without crashing.

**Actual Result:**  
The program shows that the user value isn't an integer through an error code, 
indicating a crash when the user inputs a string.

**Result:**  
Pass / **Fail**
